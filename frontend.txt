============================================================
0. CRITICAL: FOLLOW PONYTAIL
============================================================

Ponytail is enabled in this Antigravity workspace.

You MUST follow Ponytail development principles throughout this implementation.

Before writing code:

1. READ the existing repository.
2. Understand the existing frontend structure.
3. Reuse existing components.
4. Reuse existing dependencies.
5. Reuse existing utilities.
6. Reuse existing API/client code if present.
7. Do not recreate functionality that already exists.
8. Do not add a dependency if the browser, React, or an installed dependency
   already solves the problem.
9. Do not create abstractions unless they are actually needed.
10. Prefer the smallest maintainable implementation.
11. Avoid speculative architecture.
12. Avoid premature optimization.
13. Avoid unnecessary design-system duplication.
14. Avoid unnecessary wrappers.
15. Avoid unnecessary state libraries.
16. Avoid unnecessary API abstraction layers.
17. Avoid unnecessary animation libraries.
18. Avoid unnecessary packages for simple UI behavior.

Use this decision ladder:

1. Does this need to exist?
   -> If no, don't build it.

2. Does the project already have it?
   -> Reuse it.

3. Is there already an installed dependency that solves it?
   -> Use it.

4. Does React/browser/platform provide it?
   -> Use that.

5. Can it be implemented simply?
   -> Implement the simple solution.

6. Only if necessary:
   -> Introduce additional abstraction/dependency.

IMPORTANT:

Ponytail means "lazy about unnecessary complexity",
NOT "lazy about correctness".

Never sacrifice:

- security
- authorization UX
- accessibility
- data integrity
- error handling
- trust-boundary validation
- destructive-action confirmation
- document integrity
- workflow correctness
- user privacy
- responsive behavior
